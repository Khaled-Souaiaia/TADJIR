# 🇩🇿 DzPOS Pro - نظام إدارة ومحاسبة المحلات التجارية في الجزائر

برنامج مكتبي احترافي متكامل لإدارة المبيعات، المحاسبة، المخزون، ونقاط البيع (POS) للمحلات التجارية والأنشطة في الجزائر. يعمل بالكامل دون اتصال بالإنترنت (**100% Offline**) وقابل للتثبيت كبرنامج مكتبي مستقل (`.exe`) على نظام Windows عبر Electron.

---

## 🧩 التقنيات والمكتبات المستخدمة

- **واجهة المستخدم:** React 19 + Tailwind CSS مع تصميم زجاجي عصري ثلاثي الأبعاد (**Soft Glass Neumorphism**).
- **لغة البرمجة:** TypeScript.
- **قاعدة البيانات:** SQLite محلية عبر `better-sqlite3` وخدمة التخزين المحلي الدائم التلقائي.
- **تطبيق سطح المكتب:** Electron جاهز للتوزيع بصيغة `.exe` على Windows.
- **الطباعة:** دعم الطابعات الحرارية (Thermal Receipt 80mm & 58mm) وطابعات الفواتير العادية A4.
- **تصدير واستيراد البيانات:** jsPDF (تصدير PDF) و XLSX (تصدير واستيراد ملفات Excel و CSV).
- **الحركات والأنيميشن:** Framer Motion (Motion).
- **دعم الأجهزة:** قارئ الباركود التلقائي (Hardware USB/Bluetooth Barcode Scanner) وأدراج النقود النقدية (Cash Drawer).
- **تعدد اللغات:** ثنائي اللغة (العربية مع RTL والفرنسية مع LTR).

## 🧱 الوظائف والمميزات الأساسية

### 1. شاشة الدخول (Login)
- تسجيل دخول آمن بالصلاحيات مع أزرار تجريبية سريعة.
- حساب المدير: `admin` / كلمة المرور: `password` (صلاحيات كاملة).
- حساب أمين الصندوق: `cashier` / كلمة المرور: `cashier123` (صلاحيات بيع فقط).

### 2. نقطة البيع السريعة (POS)
- دعم قراءة الباركود فورياً عبر المسدس الضوئي التلقائي.
- بحث فوري بالاسم باللغتين وبالباركود.
- تصفية حسب التصنيفات.
- فئات نقدية جزائرية سريعة (500 د.ج، 1000 د.ج، 2000 د.ج، 5000 د.ج) مع احتساب الفكة والصرف المتبقي تلقائياً.
- خيارات الدفع: **نقدًا (Espèces)**، **على الحساب (Crédit)**، أو **بطاقة بنكية / ذهبية (CIB)**.

### 3. طباعة الفواتير والإيصالات
- توليد إيصال حراري احترافي 80mm أو 58mm أو فاتورة A4.
- يتضمن البيانات القانونية الجزائرية: اسم المتجر، العنوان، رقم الهاتف، السجل التجاري (RC)، الرقم الجبائي (NIF)، الرقم الإحصائي (NIS)، ورقم المادة (AI).
- زر طباعة مباشر عبر الطابعة + زر تنزيل PDF فوري.

### 4. إدارة المنتجات والمخزون
- إضافة، تعديل، وحذف المنتجات.
- توليد باركود تلقائي بالمعيار الجزائري (بادئة 613...).
- رفع صورة المنتج محليًا.
- تنبيهات مرئية ملونة عند انخفاض الكمية عن حد الأمان.
- استيراد وتصدير المنتجات عبر Excel و CSV.
- حماية: لا يمكن لحساب الكاشير حذف أي منتج.

### 5. العملاء والموردين
- إدارة بطاقات الزبائن والموردين.
- تتبع ومتابعة ديون الكريدي للزبائن ومستحقات الموردين.
- تسجيل دفعات السداد الجزئية أو الكلية.

### 6. المصروفات اليومية (Charges)
- تتبع فواتير الكهرباء والغاز (سونلغاز Sonelgaz).
- كراء المحل التجاري (Loyer).
- أجور العمال ومصاريف النقل والصيانة.

### 7. التقارير المالية والمحاسبية
- ملخص إجمالي المبيعات، وصافي الأرباح التقديرية.
- فلترة المبيعات حسب اليوم، الأسبوع، الشهر، وحسب أمين الصندوق.
- تصدير التقارير إلى Excel و PDF.
- خاص بحساب المدير فقط (محمي من وصول الكاشير).

### 8. النسخ الاحتياطي وقاعدة البيانات
- تصدير نسخة احتياطية مشفرة بضغطة زر JSON.
- تصدير سكربت SQLite متوافق (`database.db.sql`).
- استعادة النسخ الاحتياطية وإمكانية إعادة ضبط المصنع.

## ⚙️ أوامر التشغيل وتوليد ملف التثبيت Setup.exe

### 1. تشغيل التطبيق في وضع التطوير:
```bash
# تثبيت الحزم والمكتبات
npm install

# تشغيل واجهة الويب في بيئة التطوير
npm run dev

# تشغيل البرنامج المكتبي Electron محلياً
npm run electron
```

### 2. كيفية إنشاء ملف التثبيت المكتبي `DzPOS-Pro-Setup.exe` (Windows Installer):

تم ضبط إعدادات `electron-builder` و **NSIS** في ملف `package.json` لإنتاج ملف تثبيت Windows احترافي يضع أيقونة على سطح المكتب وفي قائمة إبدأ.

**الخطوة الأولى:** تأكد من تثبيت `electron` و `electron-builder`:
```bash
npm install -D electron electron-builder
```

**الخطوة الثانية:** تشغيل أمر التجميع لإنشاء `Setup.exe`:
```bash
npm run dist
```
أو:
```bash
npm run dist:win
```

**النتيجة:**
سوف يتم إنشاء مجلد جديد باسم:
```
/dist-electron/
  └── DzPOS-Pro-Setup-1.0.0.exe
```
هذا الملف هو برنامج التثبيت الكامل (**Setup.exe**) الذي يمكنك توزيعه وتثبيته على أي حاسوب Windows بدون اتصال بالإنترنت.
